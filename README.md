

> **Train Your Analytical Thinking Through CAPTCHA-Inspired Logic Puzzles**

Turify is a web-based analytical puzzle platform inspired by the legacy of **Alan Turing**. The name combines **"Turing"** with the suffix **"fy"**, representing a modern web application.

Unlike traditional CAPTCHA systems that simply verify whether a user is human, Turify transforms CAPTCHA-inspired logical challenges into an engaging training experience. It helps users improve logical reasoning, pattern recognition, spatial thinking, and decision-making skills while solving security-inspired puzzles.

----------------------------------------------------------------------------------------------------------------------

### Features

- 🧠 CAPTCHA-inspired analytical puzzles
- 📈 Real-time progress tracking
- 🏆 XP and level progression system
- 🎯 Accuracy and score calculation
- ⏱️ Average solving time tracking
- 📜 Session history
- 🌙 Dark/Light mode support
- 📱 Responsive design
- 🔄 Puzzle reset and replay
- 🎮 Interactive puzzle interface

### Objective

The primary goal of Turify is to improve users' analytical thinking through security-oriented puzzles inspired by authentication systems.

The platform focuses on:

- Logical reasoning
- Pattern recognition
- Spatial transformations
- Fast decision making
- Human verification concepts
- Security awareness

### How to Use

1. Launch the application.
2. Read the puzzle instructions.
3. Analyze the transformation sequence.
4. Choose the correct answer.
5. Submit your solution.
6. Earn XP and improve your statistics.
7. Continue solving increasingly challenging puzzles.
